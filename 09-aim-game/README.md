# 🎯 AIM FORGE

マウスAIM力を鍛える、Solarized Light調のスタイリッシュな2D精密射撃トレーナーです。
サーバー不要・依存ライブラリなしの純粋なHTML5 Canvasアプリとして全面リファクタリングしました。

## 概要

- **解像度**: 1024x768（キャンバスはCSSでビューポートに合わせてスケールされます）
- **ゲーム時間**: 60秒のタイムアタック
- **操作**: マウスのみ（狙う・クリックで撃つ）
- **世界観**: Solarized Lightパレットを基調にしたフラットデザイン（絵文字フォント非依存）

## 遊び方

1. `PLAY` ボタンをクリックしてスタート（3・2・1・GOのカウントダウン後に開始）
2. 画面に出現する的をクリックして撃つ
   - 的の中心に近いほど高スコア（連続ヒットでコンボ倍率が上昇）
   - 的にはライフタイム（残り時間リング）があり、時間切れになるとコンボがリセットされる
   - 何もない場所をクリックするとミス扱いでコンボがリセットされる
   - 時間経過とともに的は小さく・短命になり、難易度が上昇する
3. 60秒後にリザルト画面でスコア・命中率・平均ヒットスコア・最大コンボ・ベストスコアを確認
4. `RETRY (R)` でもう一度、`MENU (ESC)` でタイトルに戻る

## 操作方法

| 操作 | 内容 |
|---|---|
| マウス移動 | 照準（クロスヘア）移動 |
| 左クリック | 射撃 / メニュー・ボタン選択 |
| `Esc` | プレイ中は一時停止、リザルト画面ではメニューへ |
| `R` | リザルト画面からリトライ |
| `Enter` | タイトル画面からスタート |

## 起動方法

```bash
# 09-aim-game ディレクトリで簡易HTTPサーバーを起動
python -m http.server 8000

# ブラウザでアクセス
open http://localhost:8000
```

`index.html` をブラウザで直接開いても動作します。

## 実装詳細

- `index.html` — キャンバス1枚のみのシンプルな構成
- `style.css` — Solarized Lightパレットのページレイアウト（キャンバス以外の余白部分）
- `js/main.js` — ゲームロジック一式（状態管理・的の生成/判定・パーティクル・HUD描画）を1ファイルに実装

### 技術スタック

- Vanilla JavaScript（ES2020+、ビルド不要）
- HTML5 Canvas API（2Dコンテキストのみ、外部ライブラリなし）
- `localStorage` によるベストスコアの保存

### スコアリング

的の半径に対する命中位置の距離 `d` から連続的に計算されます（tier分けではなく滑らかな減衰）。

```
t = 1 - d / radius
score = round(100 * t^1.4)   // 5〜100点、コンボ倍率が別途加算
```

コンボ数に応じて最大+72%までスコア倍率が上昇します。

## テスト

的のスコア計算・状態遷移（spawning→alive→hit/expired→done）、コンボ倍率、命中率・平均ヒットスコア・評価ランクの算出、難易度スケーリング、ベストスコアの永続化など、ゲームロジック部分をJest（jsdom環境）でユニットテストしています。Canvas描画そのもの（`draw()`/`render()`系）は視覚的な出力であり意味のあるアサーションが書けないため対象外です。

```bash
npm install
npm test

# カバレッジ計測
npm run test:coverage
```
